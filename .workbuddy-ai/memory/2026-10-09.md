## 修复（本轮，3 个 bug + 1 加固）
1. **空弹窗根因（用户截图）**：`$this->result(..., -4, ...)` 写在 `try` 里，其抛出的 `HttpResponseException` **继承 `\Exception`** → 被同一个 try 的 `catch (Exception $e)` 又抓一次 → 转成 `error('')` → 客户端收到 `{"code":0,"msg":"","data":"","url":"","wait":3}` → 前端弹**空「温馨提示」**。修：`Addon.php` 的 install/upgrade/local 改用 `$needConfirm` 标志，`-4` 返回**移出 try**；0 问题只提示「未声明适配」。
2. **市场插件 SQL 导入失败（2014）**：插件 `install.sql` 含 `BEGIN;/COMMIT;` 时，`Db::execute()`（prepare+execute+rowCount）**留下未关闭游标** → 下一条报 `Cannot execute queries while other unbuffered queries are active`。这是 2026-10-08「getPdo()->exec() 改 Db::execute()」引入的**回归**。修：`Service::importsql()` 先 `Db::query('SELECT 1')` 确保连接，再回到 `$pdo->exec($sql)`。
3. **体检误报**：`use think\Request;` 等**未被使用**的冗余 import 被当错误（官方 version 插件正是如此，实际无害）。修：`AddonCompat::scanContent()` 先收集 import，只在真正被调用（`X::` / `extends` / `new`）时才报；并新增 `think\Controller`（TP6 已移除）检测。
4. 前端 `addon.js` 加 `errMsg()` 空消息兜底（`Addon operate failed`），杜绝空弹窗。
